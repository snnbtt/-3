1. Цель работы
Цель лабораторной работы — изучить основные принципы объектно-ориентированного программирования на языке Java, научиться создавать классы и объекты, использовать инкапсуляцию, наследование и полиморфизм, переопределять методы, сравнивать и копировать объекты, а также организовывать классы с помощью пакетов.

3. Используемые средства
Для выполнения лабораторной работы использовалась среда разработки IntelliJ IDEA и язык программирования Java.
Программа состоит из нескольких классов, каждый из которых отвечает за определённую часть задания. Для запуска программы используется класс Main, содержащий метод main().

3. Структура проекта
Проект разделён на пакеты:
main — содержит главный класс Main;
people — содержит классы Name и Person;
secrets — содержит класс Secret;
geometry — содержит классы Point и Point3D;
birds — содержит классы Bird, Sparrow, Cuckoo и Parrot;
packages — содержит класс Power.
Разделение на пакеты позволяет упорядочить исходный код и упростить работу с классами. Для обращения к классам из других пакетов используется команда import.

4. Выполнение заданий
4.1. Инкапсуляция. Классы Name и Person
В данном задании реализованы классы для хранения информации об имени и человеке.
Класс Name предназначен для хранения имени. Класс Person представляет человека и содержит поле name, в котором хранится ссылка на объект класса Name.
Для ограничения прямого доступа к данным используется модификатор private. Получение имени выполняется с помощью метода getName(), а изменение — с помощью setName().
В конструкторе проверяется, что имя не равно null. Если передано недопустимое значение, выбрасывается исключение IllegalArgumentException.
Метод setHeight() используется для изменения роста человека. Перед сохранением нового значения проверяется, что рост находится в допустимом диапазоне.
Таким образом, в задании демонстрируется инкапсуляция: данные скрыты внутри класса, а их изменение выполняется через методы с проверкой значений.

4.2. Работа с классом Secret
Класс Secret предназначен для хранения текстового значения.
Поле text объявлено с модификатором private, поэтому к нему нельзя напрямую обратиться из другого класса. Для получения текста предусмотрен метод getText().
В конструкторе выполняется проверка входного значения. Если текст равен null или является пустой строкой, программа выбрасывает исключение IllegalArgumentException.
Метод toString() используется для формирования текстового представления объекта при выводе в консоль.
В главном классе создаётся объект Secret, после чего его содержимое выводится на экран.
Задание демонстрирует создание объекта, проверку входных данных и ограничение доступа к полям класса.

4.3. Наследование. Классы Point и Point3D
Класс Point описывает точку на плоскости и содержит координаты x и y. Для хранения координат используется тип double, позволяющий работать с целыми и дробными чисами.
Конструктор класса Point принимает две координаты и сохраняет их в полях объекта.
Класс Point3D наследуется от класса Point с помощью ключевого слова extends. Он использует координаты x и y родительского класса и добавляет третью координату z.
В конструкторе Point3D вызывается super(x, y). Эта команда передаёт первые две координаты конструктору родительского класса. После этого сохраняется координата z.
Метод toString() переопределён для вывода всех трёх координат.
Задание демонстрирует наследование и повторное использование кода родительского класса.

4.4. Иерархия классов. Птицы

Для описания птиц создан абстрактный класс Bird. В нём объявлен абстрактный метод makeSound(), предназначенный для вывода звука птицы.
От класса Bird наследуются три класса:
Sparrow — представляет воробья;
Cuckoo — представляет кукушку;
Parrot — представляет попугая.
Каждый класс переопределяет метод makeSound() и выводит собственное сообщение.
Для обозначения переопределения используется аннотация @Override. Она помогает компилятору проверить, что метод действительно переопределяет унаследованный метод.
Абстрактный класс задаёт общую структуру для всех птиц, а конкретные классы определяют их поведение.

4.5. Полиморфизм. Птичий рынок

В главном классе создаётся массив типа Bird, в котором находятся объекты классов Sparrow, Cuckoo и Parrot.
Для перебора элементов используется цикл for-each. На каждой итерации вызывается метод makeSound() текущего объекта.
Несмотря на то что переменная цикла имеет общий тип Bird, выполняется реализация метода конкретного объекта. Поэтому разные птицы выводят разные сообщения.
Это является примером полиморфизма — возможности работать с объектами разных классов через общий родительский тип.
В текущей реализации демонстрируется вызов переопределённого метода для разных объектов. Если в методических указаниях для задания «Птичий рынок» предусмотрены дополнительные требования, их необходимо учесть отдельно.

4.6. Сравнение объектов Point

В классе Point переопределён метод equals(), который используется для сравнения объектов.
Сначала проверяется, не являются ли обе ссылки ссылками на один объект. Затем проверяется, относится ли переданный объект к типу Point.
После этого сравниваются координаты x и y. Для сравнения значений типа double используется метод Double.compare().
Метод возвращает true, если обе координаты совпадают, и false, если хотя бы одна из них отличается.
Также переопределён метод hashCode(), который вычисляет хеш-код на основе координат точки.
В главном классе создаются две точки с одинаковыми координатами и выводится результат их сравнения.
Задание показывает, как можно определить собственные правила сравнения объектов.

4.7. Работа с пакетами. Возведение в степень

Для вычисления степени числа создан класс Power. В нём реализован статический метод pow(), который принимает основание и целочисленную степень.
Если степень равна нулю, метод возвращает 1. Если степень отрицательная, вычисляется обратное значение. Для положительной степени используется цикл for.
Переменная result изначально равна единице. На каждой итерации она умножается на основание числа. После завершения цикла результат возвращается с помощью return.
Метод объявлен как static, поэтому его можно вызвать без создания объекта класса. Например, вызов Power.pow(2, 3) возвращает 8.0.
Закрытый конструктор класса Power предотвращает создание экземпляров этого класса.
Задание демонстрирует организацию вспомогательного метода в отдельном классе и использование циклов для выполнения вычислений.

4.8. Копирование точки методом clone()

В классе Point реализован метод clone(), создающий новый объект с координатами исходной точки.
Метод возвращает результат создания нового объекта через new Point(x, y). Таким образом, копия имеет те же координаты, но является отдельным объектом.
В главном классе создаётся исходная точка, затем вызывается метод clone(). После этого выводятся оригинал и копия.
Задание демонстрирует создание копии объекта и различие между копированием ссылки и созданием нового объекта.
